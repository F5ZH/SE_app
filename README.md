# 词汇记忆 - 基于艾宾浩斯遗忘曲线的背单词应用

一个功能完整的背单词应用，采用艾宾浩斯遗忘曲线算法，帮助用户高效记忆单词。

## ✨ 主要功能

### 📚 词书管理
- **预设词书**：内置四级、六级、托福、雅思等常用词书
- **自定义导入**：支持从文件导入或手动输入词书
- **词书预览**：查看词书内容和统计信息

### 📅 学习计划
- **智能规划**：根据每日新词量自动计算完成时间
- **进度跟踪**：实时显示学习进度和掌握程度
- **灵活调整**：支持修改学习计划参数

### 🧠 科学记忆
- **艾宾浩斯算法**：基于遗忘曲线的智能复习安排
- **质量评分**：根据掌握程度调整复习间隔
- **生词标记**：错误回答自动标记生词，提高复习频率
- **学习统计**：详细的准确率和进度数据

### 🎨 极简设计
- **平面风格**：简洁现代的UI设计
- **响应式布局**：支持各种屏幕尺寸
- **流畅动画**：提升用户体验

### 🔍 查词功能
- **权威词典**：集成Merriam-Webster在线词典
- **一键查词**：学习过程中快速查词

### 📝 多种学习模式
- **看英语回忆汉语**：传统记忆模式
- **看汉语拼写英语**：拼写练习模式
- **看英语选择汉语**：四选一选择题模式

### 📄 PDF导出
- **今日单词表**：导出当日学习任务为PDF
- **离线学习**：支持打印和离线复习

## 🔧 核心算法

### 艾宾浩斯遗忘曲线
应用实现了基于SuperMemo算法的遗忘曲线系统：

- **初始间隔**：1天
- **间隔递增**：1, 2, 4, 7, 15, 30, 60, 120天
- **难度系数**：根据回答质量动态调整
- **质量评分**：1-5分，影响复习间隔

### 学习记录结构
```typescript
interface StudyRecord {
  wordId: string;        // 单词ID
  word: string;          // 单词
  correctCount: number;  // 正确次数
  wrongCount: number;    // 错误次数
  lastReviewed: number;  // 最后复习时间
  nextReview: number;    // 下次复习时间
  interval: number;      // 复习间隔（天）
  easeFactor: number;    // 难度系数
  reviewCount: number;   // 复习次数
}
```

## 🎯 使用指南

### 1. 创建学习计划
1. 选择词书（预设或自定义）
2. 设置每日新词量（建议10-50个）
3. 选择开始日期
4. 系统自动计算完成时间

### 2. 开始学习
1. 点击"开始学习"选择学习模式
2. 选择学习模式：看英语回忆汉语、看汉语拼写英语、看英语选择汉语
3. 先学习新词，再复习旧词
4. 根据记忆程度评分（1-5分）
5. 系统自动安排下次复习时间
6. 错误回答会增加生词标记，提高复习频率

### 3. 导入词书
支持两种导入方式：

**文件导入**：
- 支持.txt和.csv格式
- 每行一个单词，制表符分隔
- 格式：`单词	翻译	音标	例句	难度等级`

**手动输入**：
- 直接在界面输入词书信息
- 支持批量添加单词

### 4. PDF导出
- 在学习界面点击"导出PDF"按钮
- 自动生成包含新词和复习词的PDF文件
- 支持离线学习和打印
